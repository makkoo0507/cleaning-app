**プロジェクト名:** 民泊清掃管理アプリ
**作成日:** 2026-06-20
**バージョン:** 1.0（2026-06-24 統合・整理／2026-08-05 ユースケース・業務フローを統合）

## 1. プロジェクト概要

### 1.1 背景・目的

民泊清掃業務において、業者・民泊オーナー・フリーランス清掃者の3者間のコミュニケーションや業務管理が、現状では電話・メール・LINE の個別やりとりに頼っており非効率な状態にある。

本システムにより、スケジュール管理・通知・清掃記録の共有を一元化し、業務効率と品質を向上させる。

将来的には複数の業者に提供する SaaS として展開する。1社目は開発・テスト運用とし、2社目以降からフリーミアム型の商用サービスとして公開する。

### 1.2 プランと料金体系

プランは**物件数・清掃者数の登録上限**を決める。

| プラン | 対象 | 民泊物件数上限 | 清掃者数上限 | 月額 |
| --- | --- | --- | --- | --- |
| **フリープラン** | 2社目以降・導入初期 | 1件 | 5名 | 無料 |
| **有料プラン** | 上限を超えた場合 | 無制限 | 無制限 | 別途設定 |

- 上限に達した場合、新規登録をブロックしてアップグレードを促す
- プラン管理はベンダーがデータベース上で行う（DB の `contractors.plan` カラムで制御）

#### 1.2.1 有料オプション

プランとは独立した**追加機能**。ベンダーが業者ごとに `contractor_features` テーブルで ON/OFF を管理する。

| オプション | 機能概要 |
| --- | --- |
| **請求・支払い** | 案件ごとの請求額・支払い額の記録、月次集計、CSV エクスポート |

- 加入・解約はベンダー（システム管理者）が対応する
- 業者管理者は「設定 > オプション」で加入状況を確認できる
- 未加入の業者が該当画面を開くと「システム管理者へお申し込みください」と案内される

## 2. システム構成

### 2.1 プラットフォーム

| 画面 | 対象 | 技術 |
|---|---|---|
| **ベンダー管理画面** | ベンダー運営 | ブラウザ（`/vendor`） |
| **管理 Web アプリ** | 業者 | ブラウザ（PC 主体） |
| **LINE Mini App (LIFF)** | 清掃者・民泊オーナー | LINE アプリ内 Web ビュー |

### 2.2 通知

- **LINE Messaging API** を使用
- 業者がそれぞれ自社の LINE 公式アカウントを開設し、Channel Access Token / Channel Secret を本システムに登録する
- 清掃者・民泊オーナーは各業者の LINE 公式アカウントを友だち追加して通知を受信する
- 通知の送信元は業者ごとに異なる（業者ブランドで送信される）

### 2.3 LINE アカウントの二層構造

| レイヤー | 誰のアカウント | 役割 |
|---|---|---|
| **LINE Login / LIFF** | **ベンダー共通（1 つ）** | ログイン・本人確認、LINE Mini App 画面の入口 |
| **Messaging API（公式アカウント）** | **各業者ごと** | 通知メッセージの送信元。業者ブランドで届く |

### BF-00｜LINE 公式アカウント開設・Token 登録

アプリで LINE 通知を使い始める前に1回だけ実施する。

```
業者管理者
  │
  ├─ 1. LINE 公式アカウントを開設
  │       └─ LINE Business Manager（business.line.me）でアカウントを作成
  │
  ├─ 2. Messaging API チャネルを作成
  │       └─ LINE Developers Console（developers.line.biz）でプロバイダーを作成
  │               └─ 「新規チャネル作成」→「Messaging API」を選択して作成
  │
  ├─ 3. 認証情報を取得
  │       ├─ Channel Secret:「チャネル基本設定」タブに表示
  │       └─ Channel Access Token:「Messaging API 設定」タブ → 「発行」ボタンで取得
  │
  └─ 4. 管理 Web アプリから Token を登録
          └─ 設定画面で Channel Access Token・Channel Secret を入力して保存
                  └─ contractors テーブルに保存される
```

> LINE 通知（BF-03, BF-04）は Token が登録されていない業者には送信されない。

### BF-01｜初期セットアップ

業者が初めてアプリを使い始める際のセットアップ手順。LINE 紐付けの詳細は BF-02 を参照。

```
業者管理者
  │
  ├─ 1. 物件を登録
  │       └─ 物件名・住所・特記事項を入力
  │
  ├─ 2. 物件関係者を登録
  │       ├─ ユーザー情報（名前）を登録 → invite_token 発行
  │       ├─ 物件への紐付け・役割（owner / operations / sales）・通知設定
  │       └─ 招待 URL を LINE や SMS で関係者本人に送付
  │
  ├─ 3. 清掃者を登録
  │       ├─ ユーザー情報（名前）を登録 → invite_token 発行
  │       └─ 招待 URL を LINE や SMS で清掃者本人に送付
  │
  └─ 4. 社員を登録（必要な場合）
          └─ メール・パスワードでアカウント発行
```

### BF-02｜LINE アカウント紐付け

物件関係者・清掃者が初回利用時に LINE アカウントを紐づける。

> **前提（LINE アカウントの二層構造）**: ログインに使う LIFF は**ベンダー共通**、通知の送信元は**各業者の公式アカウント**。
> そのため「LIFF 紐付け（本人確認）」と「業者公式アカウントの友だち追加（通知受信）」は**別の作業**で、両方そろって初めて通知が届く。詳細は[2.3 LINE アカウントの二層構造](#23-line-アカウントの二層構造)を参照。

```
業者管理者
  └─ 1. 管理 Web で招待 URL を発行・コピー
          └─ URL 例: https://example.vercel.app/liff/invite?token={invite_token}

  └─ 2. 招待 URL を LINE または SMS で相手に送付（アプリ外）
          └─ あわせて「自社の LINE 公式アカウントの友だち追加 URL/QR」も案内する

対象者（清掃者 または 物件関係者）
  └─ 3. 招待 URL をタップ → ロールに応じた LINE Mini App（LIFF）が起動

  └─ 4. LINE でログイン（LIFF 認証＝ベンダー共通）

  └─ 5. システムがトークンを照合
          ├─ 一致: users.line_user_id を保存 → invite_token を NULL クリア
          └─ 不一致 / 期限切れ: エラー表示

  └─ 6. 担当業者の LINE 公式アカウントを友だち追加（通知受信に必須）
          └─ LIFF の友だち追加機能では業者ごとのアカウントは追加できないため別導線

  └─ 7. 紐付け＋友だち追加 完了 → 以降は業者公式アカウントから LINE 通知が届く
          └─ 日常は通知メッセージ内のリンク（liff.line.me/{LIFF ID}）から Mini App を開く
```

### BF-03｜スケジュール登録

チェックアウト日が確定したタイミングで清掃案件を登録する。

```
業者（管理者 または 社員）
  │
  ├─ 1. スケジュール作成
  │       ├─ 対象物件・清掃日・開始予定時刻を入力
  │       └─ 清掃者をアサイン（後でアサインも可）
  │
  └─ 2. 作成完了 → 自動通知
          │
          ├─ 清掃者へ LINE 通知
          │       「〇月〇日 〇〇物件の清掃が入りました」+ 詳細リンク
          │
          └─ 物件の通知有効な関係者へ LINE 通知
                  「〇月〇日に清掃が予定されました」+ 詳細リンク
```

### BF-04｜清掃実施

清掃当日の記録登録から完了通知までの流れ。

```
【前日】
  システム（自動）
    └─ 清掃者へ LINE リマインド通知
            「明日 〇〇物件の清掃があります」

【当日】
  清掃者（LINE Mini App）
    │
    ├─ 1. マイスケジュールで案件・物件情報を確認
    │
    ├─ 2. 清掃開始 → 開始時刻を登録
    │
    ├─ 3. 清掃作業
    │
    └─ 4. 清掃完了 → 完了時刻・メモを登録
            │
            └─ 完了 → 自動通知
                    │
                    ├─ 物件の通知有効な関係者へ LINE 通知
                    │       「清掃が完了しました（完了時刻・所要時間）」
                    │
                    └─ 業者へ LINE 通知
                            「〇〇さんが〇〇物件の清掃を完了しました」

【完了後】
  物件関係者（LINE Mini App）
    └─ 清掃記録（完了時刻・所要時間・メモ）を閲覧

  業者（管理 Web）
    └─ 清掃記録を一覧で確認
```

### BF-05｜請求・支払い管理


## 5. 機能要件

### 5.1 業者（管理 Web アプリ）

画面のナビゲーション構成：

```
ダッシュボード
スケジュール
清掃記録
請求・支払い（オプション加入時のみ）
基本情報 ▶︎
  物件
  オーナー
  清掃者
設定 ▶︎（管理者のみ）
  LINE連携
  通知設定
  オプション
  ユーザー管理
```

#### 5.1.1 物件管理

- 民泊物件の登録・編集・削除（物件名、住所、特記事項）
- 物件ごとに複数の関係者を登録・管理
- 関係者ごとに LINE 通知の ON/OFF を設定できる

#### 5.1.2 オーナー管理

- 関係者（オーナー・運用担当・営業など）の登録・編集・削除
- 各ユーザーへの LINE アカウント紐付け

#### 5.1.3 清掃者管理

- 清掃者（フリーランス）の登録・編集・削除
- 各ユーザーへの LINE アカウント紐付け

#### 5.1.4 スケジュール管理

- 清掃案件の作成（対象物件、清掃日時、担当清掃者のアサイン）
- スケジュールの一覧表示・編集・削除

#### 5.1.5 通知送信

- スケジュール作成時に、担当清掃者と物件の通知有効な関係者へ LINE 通知を自動送信
- 清掃前日・当日に清掃者・オーナーへリマインド通知を自動送信（業者ごとに送信先・タイミングを設定可能）
- 清掃完了時に物件の通知有効な関係者へ完了通知を自動送信

#### 5.1.6 清掃記録閲覧

- 全案件の清掃記録（完了時刻・所要時間）を一覧表示

#### 5.1.7 請求・支払い管理（オプション）

- 清掃案件ごとの金額（請求額・支払い額）を記録
- 月次・期間別の集計表示
- CSV エクスポート機能

#### 5.1.8 ユーザー管理（管理者のみ）

- スタッフアカウントの登録・編集・削除
- 権限：管理者 / 閲覧者

#### 5.1.9 設定

- LINE Messaging API のトークン・チャネルシークレット登録
- リマインド通知の送信先・タイミング設定
- オプション機能の利用 ON/OFF

---

### 5.2 清掃者（LINE Mini App）

- 自分がアサインされた清掃案件の一覧・詳細表示
- 清掃開始・完了時刻の記録、メモ入力

---

### 5.3 民泊オーナー（LINE Mini App）

- 自物件に紐づいた清掃案件の一覧表示
- 清掃完了後の記録（完了時刻・所要時間・メモ）を閲覧
